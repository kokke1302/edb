## 役割

本ファイルは、開発中アプリプロジェクト内の、ファイル名と責務を一覧化し、特にAIによる新規機能・修正時のコード重複およびデータ構造不一致を防止することを目的とする。

## 凡例

- レイヤー:
  - Data: データモデル、外部I/O（DB/API）接続ロジック
    - `ファイル名`
      - `クラス`
        - プロパティ
          - `格納型` キー: 役割
        - メソッド
          - `return型` `関数名`: 役割
  - Domain: ビジネスロジック、状態管理（Notifier）
    - `ファイル名`
      - `プロバイダー型` プロバイダー名
      - `クラス`
        - 責務
          - クラスの説明
        - 保有データ: `dataレイヤーのクラス名`
        - メソッド
          - `return型` `関数名`: 役割
  - Presentation: UI (Widget)
    - `ファイル名`
      - 依存ドメイン
        - `dmainレイヤー.dart`（依存ファイル）
      - 表示内容
        - 場所（右上とか）: 表示内容、イベント
      - 子UIファイル
        - `presentationレイヤー.dart`（子ウィジェットの関係にあるファイル）
- 依存方向: 下のレイヤーが上のレイヤーをインポートすることは基本的に禁止 (Presentation -> Domain -> Data の一方向のみ)。

## ファイルの責務

### Data

- `card_state.dart`
  - `Based` (enum)
    - `vocabularies`: 単語帳DB
    - `dictionary`: 内部辞書DB
    - `init`: 初期値/その他
  - `CardEntry`
    - プロパティ
      - `int` id: エントリの固有ID（DB IDなど）
      - `String` word: 対応する英単語
      - `String` translation: 訳語
      - `bool` isShow: デフォルトの表示設定
      - `bool` nowShow: 現在の表示状態
      - `String` memo: メモ/補足情報
      - `Based` based: 訳語の出典元
    - メソッド
      - `CardEntry` copyWith({`int`? id, `String`? word, `String`? translation, `bool`? isShow, `bool`? nowShow, `String`? memo, `Based`? based}): プロパティを変更した新しいCardEntryを返す
      - `Map<String, dynamic>` toJson(): CardEntryオブジェクトからJSON形式へ変換
      - `CardEntry` fromJson(`Map<String, dynamic>` json): JSON形式からCardEntryオブジェクトへ変換

- `cardlist_state.dart`
  - `CardListState`
    - プロパティ
      - `CardEntry`? showWord: 現在選択され、翻訳に反映される情報
      - `List<CardEntry>` vocabularyWords: 単語帳DBからの訳語リスト
      - `List<CardEntry>` dictionaryWords: 内部辞書DBからの訳語リスト
    - メソッド
      - `CardListState` copyWith({required `CardEntry`? showWord, `List<CardEntry>`? vocabularyWords, `List<CardEntry>`? dictionaryWords}): 状態の一部を更新した新しいCardListStateを返す

- `token_id.dart`
  - `NotifierProvider<TokenIdNotifier, int>` tokenIdProvider: stateを提供
  - `TokenIdNotifier`
    - プロパティ
      - `int` state: 現在選択されているTokenのID（初期値`-1`）
    - メソッド
      - `void` updateNum(`int` num): 状態（Token ID）を更新する

- `sentence_list.dart`
  - `TileState`
    - プロパティ
      - `List<Tile>` list: 保存されている英文のリスト
      - `bool` isProcessing: 処理中かどうか
    - メソッド
      - `TileState` copyWith({`List<Tile>`? list, `bool`? isProcessing}): 状態の一部を更新した新しいTileStateを返す

- `sentence.dart`
  - `Tile`
    - プロパティ
      - `int` id: 固有ID
      - `String` text: 表示する英文全体
      - `List<Token>` chain: 英文を構成するTokenのリスト
    - メソッド
      - `Tile` copyWith({`int`? id, `String`? text, `List<Token>`? chain}): プロパティを変更した新しいTileを返す

- `redidata_receiver.dart`
  - `NotifierProvider<RegiDataReceiver, RegistrationState>` regiDataReceiver: stateを提供
  - `RegiDataReceiver`
    - プロパティ
      - `RegistrationState` state: 登録画面が保持する情報
    - メソッド
      - `void` receiveCard({required `CardEntry` card}): 登録済みカードから受け取る
      - `void` receiveList({required Vocabulary entry}): 内部辞書から受け取る
      - `void` reciveOriginal({required String englishWord}): オリジナル訳の登録をする
      - `void` reciveNew(): ゼロから登録する

- `registration_state.dart`
  - `RegistrationState`
    - プロパティ
      - `int` id: 単語帳のid（登録されていない場合`-1`）
      - `String` englishWord: 英単語
      - `String` japaneseTranslation: 日本語訳
      - `bool` isHidden: 翻訳時に非表示にする
      - `String` memo: メモ
      - `Based` based: どこからの情報か
      - `bool` isProcessing: 処理中フラグ
    - メソッド
      - `RegistrationState` copyWith({`CardEntry`? card, `bool`? isProcessing}): 状態を変更した新しいインスタンスを返す

- `bottom_index.dart`
  - `NotifierProvider<BottomNavIndexNotifier, int>` bottomNavIndexProvider: stateを提供
  - `BottomNavIndexNotifier`
    - プロパティ
      - `int` state: 現在選択されているボトムナビゲーションバーのインデックス
    - メソッド
      - `void` setIndex(`int` newIndex): 状態（インデックス）を更新する

- `token.dart`
  - `Token`
    - プロパティ
      - `int` id: 固有ID
      - `bool` isWord: 単語であるかどうか
      - `CardEntry` card: 訳語関連の情報（id, word, translation, isShow, nowShow, memo, based）
    - メソッド
      - `Token` copyWith({`int`? id, `bool`? isWord, `CardEntry`? card}): プロパティを変更した新しいTokenを返す
      - `Map<String, dynamic>` toJson(): TokenオブジェクトからJSON形式へ変換
      - `Token` fromJson(`Map<String, dynamic>` json): JSON形式からTokenオブジェクトへ変換

- `translation_state.dart`
  - `TranslationState`
    - プロパティ
      - `String` originalText: 元の英文
      - `List<Token>` tokens: トークン（単語、句読点）のリスト
      - `bool` isProcessing: 処理中（解析・辞書検索中）かどうか
    - メソッド
      - `TranslationState` copyWith({`String`? originalText, `List<Token>`? tokens, `bool`? isProcessing}): プロパティを変更した新しい状態を返す
      - `Token` targetToken({required `int` id}): 指定されたIDのTokenを取得する

- `list_state.dart`
  - `EndStatus` (enum)
    - `normal`
    - `loading`
    - `error`
  - `WordListState`
    - プロパティ
      - `List<Vocabulary>` words: 単語リスト本体（DBエンティティ）
      - `EndStatus` endStatus: リスト画面下部に表示すべき状態
      - `bool` isDataEnd: 全てのデータがロードされたか
    - メソッド
      - `WordListState` copyWith({`List<Vocabulary>`? words, `EndStatus`? endStatus, `bool`? isDataEnd}): 状態の一部を更新した新しいWordListStateを返す

- `sort_setting.dart`
  - `SortField` (enum)
    - `createdAt`: 作成日時
    - `englishWord`: 英単語
  - `SortOrder` (enum)
    - `asc`: 昇順
    - `desc`: 降順
  - `SortSetting`
  - プロパティ
    - `SortField` field: ソート項目
    - `SortOrder` order: ソート順序
    - `String` searchWord: 確定検索文字列
    - `String` typingWord: 入力中検索文字列
  - メソッド
    - `SortSetting` copyWith({`SortField` field, `SortOrder` order, `String` searchWord, `String` typingWord}): 設定の一部を変更した新しいSortSettingを返す

- `bottom_index.dart`
  - `NotifierProvider<BottomNavIndexNotifier, int>`: stateを提供
  - `BottomNavIndexNotifier`
    - プロパティ
      - `int` state: 現在選択されているボトムナビゲーションバーのID（初期値: `0`）
    - メソッド
      - `void` setIndex(`int` newIndex): 状態を更新

### Domain

- `card_repository.dart`
  - `Provider<CardRepository>` cardRepositoryProvider
  - `CardRepository`
    - 責務
      - 単語カード情報 (CardEntry) の取得（Read）に特化
      - 単語帳DB (`Vocabularies`) および 内部辞書DB (`InternalDictionaries`) から特定の英単語に紐づく訳語エントリを読み込み、CardEntryリストとして返す
    - 保有データ: `AppDatabase` (DB接続)
    - メソッド
      - `Future<List<CardEntry>>` fetchVocabularyEntries(`String` englishWord): 単語帳DBから`CardEntry`リストを取得
      - `Future<List<CardEntry>>` fetchDictionaryEntries(`String` wordKey): 内部辞書DBから`CardEntry`リストを取得

- `cardlist_notifier.dart`
  - `AsyncNotifierProvider.autoDispose<CardListNotifier, CardListState>` cardListProvider
  - `CardListNotifier`
    - 責務
      - 特定のTokenが持つ訳語の候補リスト (`vocabularyWords`, `dictionaryWords`) と、現在選択されている訳語 (`showWord`) を管理
      - `tokenIdProvider`、`translationProvider`、`cardRepositoryProvider`に依存
      - 選択された訳語をTokenに反映し、`translationProvider`を更新する
    - 保有データ: `CardListState`
    - メソッド
      - `Future<CardListState>` build(): `tokenId`から対象Tokenを取得し、`CardRepository`を用いて訳語候補リストを初期ロードする
      - `void` toggleShowWord(`CardEntry` entry): 選択された`CardEntry`の状態を切り替え、`showWord`を更新し、`translationProvider`に反映する
      - `void` updateEntry(): `showWord`が更新された際に、その内容を`translationProvider`内のTokenに反映する

- `tile_repository.dart`
  - `Provider<TileRepository>` tileRepositoryProvider
  - `TileRepository`
    - 責務
      - 英文履歴データ (Tile)のCRD処理に特化
      - `List<Token>`をJSON文字列に変換してDBに保存・読み込みを行う
    - 保有データ: `AppDatabase` (DB接続)
    - メソッド
      - `Future<int>` createTile({`String` text, `List<Token>` chain}): 新しい英文 (`Tile`) をDBに保存
      - `Future<List<Tile>>` fetchAllTiles(): 全ての英文履歴 (`Tile`) をDBから読み込む
      - `Future<int>` deleteTile(`int` id): 指定IDの英文履歴をDBから削除

- `tilelist_notifier.dart`
  - `AsyncNotifierProvider<TileListNotifier, TileState>` tileListProvider
  - `TileListNotifier`
    - 責務
      - 保存された英文履歴のリスト (`list`) と処理状態 (`isProcessing`) を管理
      - `tileRepositoryProvider`、`translationProvider`に依存
    - 保有データ: `TileState`
    - メソッド
      - `Future<TileState>` build(): 起動時に`TileRepository`を用いて全英文履歴リストを初期ロードする
      - `Future<void>` addTile(): 現在の翻訳状態 (`translationProvider`) の英文を`TileRepository`経由でDBに保存し、リストに追加する
      - `Future<void>` deleteTile(`int` id): `TileRepository`経由でDBから削除し、リストから削除する

- `registration_notifier.dart`
  - `NotifierProvider.autoDispose<RegistrationNotifier, RegistrationState>` registrationProvider
  - `RegistrationNotifier`
    - 責務
      - 単語の登録/編集画面の状態 (`CardEntry`, `isProcessing`) を管理
      - 画面の入力値（英単語、訳語、メモ）の更新を反映
      - `vocabularyRepositoryProvider`、`cardReceiver`に依存
    - 保有データ: `RegistrationState`
    - メソッド
      - `RegistrationState` build(): 起動時に`regiDataReceiver`を用いて登録画面に表示するデータを初期ロードする
      - `void` updateEnglish(`String` text): 英単語の入力値を更新
      - `void` updateTranslation(`String` text): 訳語の入力値を更新
      - `void` updateMemo(`String` text): メモの入力値を更新
      - `void` toggleIsShowing(bool isHidden): 初期表示の更新
      - `Future<void>` save(): 入力された`CardEntry`を`VocabularyRepository`経由で保存/更新し、`cardListProvider`を更新する
      - `Future<void>` delete(): 既存の`CardEntry`を`VocabularyRepository`経由でDBから削除する

- `vocaburary_repository.dart`
  - `Provider<VocabularyRepository>` vocabularyRepositoryProvider
  - `VocabularyRepository`
    - 責務
      - 単語帳DB (`Vocabularies`) のCUD操作に特化
      - `CardEntry`を受け取り、DB操作（挿入、更新、削除）を行う
      - 排他制御（`isShow=true`に設定されたエントリがある場合、同じ単語の他のエントリを`isHidden=true`にする）を実装
    - 保有データ: `AppDatabase` (DB接続)
    - メソッド
      - `Future<int>` _setAllOthersHidden({required `String` word}): 同じ単語の全エントリを非表示に更新（排他制御用）
      - `Future<bool>` addVocabulary({required `CardEntry` card}): 単語をDBに挿入
      - `Future<int>` updateVocabulary({required `CardEntry` card}): 単語をDBで更新
      - `Future<int>` deleteVocabulary({required `CardEntry` card}): 単語をDBから削除

- `batch_repository.dart`
  - `Provider<BatchRepository>` batchRepositoryProvider
  - `BatchRepository`
    - 責務
      - 複数の検索キー（単語）に対する単語帳DBからの訳語を一括で取得する
    - 保有データ: `AppDatabase` (DB接続)
    - メソッド
      - `Future<List<Vocabulary>>` fetchTranslationsBatch(`Set<String>` lookupKeys): 複数の単語キーに対応するVocabularyエントリをDBから一括取得

- `text_processor.dart`
  - `Provider<TextProcessor>` textProcessorProvider
  - `TextProcessor`
    - 責務
      - 英文の解析、トークン化、辞書検索、訳語割り当てのロジックを実装
      - `BatchRepository`を使用して、Token化された単語の訳語を一括で取得し、Tokenに割り当てる
    - 保有データ: `Ref` (Riverpod)
    - メソッド
      - `List<Token>` _tokenizeText({required `String` text}): テキストをTokenに分割し、CardEntryの初期値を設定する共通ロジック
      - `Future<List<Token>>` incrementalTranslation({required `List<Token>` nowTokens, required `String` newText}): 既存のTokenと新テキストから差分を検出し、部分的に更新・訳語を割り当てる（差分更新用）
      - `Future<List<Token>>` fullTranslation({required String text}): 再翻訳時に使用

- `translation_notifier.dart`
  - `NotifierProvider<TranslationNotifier, TranslationState>` translationProvider
  - `TranslationNotifier`
    - 責務
      - 翻訳画面のメインの状態 (`originalText`, `tokens`, `isProcessing`) を管理
      - 英文入力の変更やボタン押下をトリガーに、`TextProcessor`を呼び出し、翻訳処理を実行
      - 処理にはスロットリング (`Throttle`) を適用
    - 保有データ: `TranslationState`
    - メソッド
      - `TranslationState` build(): 初期状態の生成
      - `void` restore({required `String` text, required `List<Token>` chain}): 英文履歴からの状態復元
      - `void` updateToken({required `Token` updatedToken}): 特定のTokenの訳語情報を更新
      - `void` updateOriginalText({required `String` newText}): 英文入力の更新と自動翻訳トリガー
      - `void` pushTriggerButton(): 手動翻訳のトリガー
      - `void` _processTranslation({`List<Token>`? nowTokens}): 翻訳処理のメインロジック（`TextProcessor`の呼び出し）

- `list_notifier.dart`
  - `AsyncNotifierProvider.autoDispose<WordListNotifier, WordListState>` wordListProvider

      - `Future<List<Vocabulary>>` _fetchData({required `int` offset, required `int` limit, required `String` queryText}): Repositoryからデータを取得する内部メソッド

- `list_repository.dart`

### Presentation

- `dictionary_card.dart`

## データベース

作成済みのテーブル

### 単語帳テーブル（Vocabularies）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー、自動インクリメント |
| englishWord | text | 英単語（小文字で保存、ユニーク制約） |
| japaneseTranslation | text | 日本語訳 |
| isHidden | boolean | 既定値は非表示か（0: false, 1: true） |
| memo | text | ユーザーメモ |
| created_at | dateTime | 登録日時 |
| updated_at | dateTime | 更新日時 |

### 内部辞書テーブル（InternalDictionaries）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー |
| key | integer | 英単語（小文字のみ） |
| word | text | 英単語（大文字・小文字混合、表示に用いる） |
| mean | text | 日本語訳 |
| memo | text | ユーザーメモ（nullable） |

### 英文テーブル（EnglishTexts）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー、自動インクリメント |
| original_text | text | 元の英文全体 |
| parsed_words_json | text | 解析された単語のリスト（JSON形式で保存） |
| created_at | dateTime | 保存日時 |
| updated_at | dateTime | 更新日時 |
