## 役割

本ファイルは、開発中アプリプロジェクト内の、ファイル名と責務を一覧化し、特にAIによる新規機能・修正時のコード重複およびデータ構造不一致を防止することを目的とする。

## 凡例

- レイヤー:
  - Data: データモデル、外部I/O（DB/API）接続ロジック
    - `ファイル名`
      - `クラス`
      - プロパティ
        - `格納型` キー: 役割
        - `格納型` キー: 役割
      - メソッド
        - `return型` メソッド: 役割
  - Domain: ビジネスロジック、状態管理（Notifier）
    - `ファイル名`
      - `クラス`
      - 責務
        - クラスの説明
      - 保有データ: `dataレイヤーのクラス名`
      - メソッド
        - `return型` メソッド: 役割
  - Presentation: UI (Widget)
    - `ファイル名`
      - 依存ドメイン
        - `dmainレイヤー.dart`（依存ファイル）
      - 表示内容（UI構成上の役割）
        - 場所（右上とか）: 何を表示するか
      - 子UIファイル
        - `presentationレイヤー.dart`（子ウィジェットの関係にあるファイル）
- 依存方向: 下のレイヤーが上のレイヤーをインポートすることは基本的に禁止 (Presentation -> Domain -> Data の一方向のみ)。

## ファイルの責務

### Data

- `token.dart`
  - `Token`
  - プロパティ
    - `int` id: 固有ID
    - `String` word: 表示する単語（大文字OK）
    - `bool` isWord: 単語であるかどうか
    - `String` resolvedTranslation: 最終的に表示される訳語
    - `bool` nowShow: 訳語を表示するかどうか
    - `int` vocId: 単語帳DBのID
  - メソッド
    - `Token` copyWith({`String`? resolvedTranslation, `bool`? nowShow, `int`? vocId}): 訳語関連のプロパティを変更した新しいTokenを返す

- `translation_state.dart`
  - `TranslationState`
  - プロパティ
    - `String` originalText: 元の英文
    - `List<Token>` tokens: トークン（単語、句読点）のリスト
    - `bool` isProcessing: 処理中（解析・辞書検索中）かどうか
  - メソッド
    - `TranslationState` copyWith({`String`? originalText, `List<Token>`? tokens, `bool`? isProcessing}): プロパティを変更した新しい状態を返す
    - `Token` targetToken({required `int` id}): 指定されたIDのTokenを取得する

- `card_state.dart`
  - `CardEntry`
  - プロパティ
    - `int` id: エントリの固有ID（DB IDなど）
    - `String` translation: 訳語
    - `bool` isShow: デフォルトの表示設定（単語帳DBに設定された表示/非表示）
    - `bool` nowShow: 現在の表示状態（モーダルシート内での一時的な表示/非表示）
    - `String` memo: メモ/補足情報
    - `Based` based: 訳語の出典元（`vocabularies` or `dictionary`）
  - メソッド
    - `CardEntry` nowShowChange({`bool`? nowShow}): `nowShow`プロパティを変更した新しいCardEntryを返す

- `cardlist_state.dart`
  - `CardListState`
  - プロパティ
    - `CardEntry`? showWord: 現在選択され、親Tokenに反映されるCardEntry
    - `List<CardEntry>` vocabularyWords: 単語帳DBからの訳語リスト
    - `List<CardEntry>` dictionaryWords: 内部辞書DBからの訳語リスト
  - メソッド
    - `CardListState` copyWith({required `CardEntry`? showWord, `List<CardEntry>`? vocabularyWords, `List<CardEntry>`? dictionaryWords}): 状態の一部を更新した新しいCardListStateを返す

- `token_id.dart`
  - `TokenIdNotifier`
  - プロパティ
    - `int` state: 現在選択されているTokenのID
  - メソッド
    - `void` updateNum(`int` num): 状態（Token ID）を更新する

- `list_state.dart`
  - `WordListState`
  - プロパティ
    - `List<Vocabulary>` words: 単語リスト本体（DBエンティティ、推測）
    - `EndStatus` endStatus: 下部に表示すべき状態（`normal`, `loading`, `error`）
    - `bool` isDataEnd: 全てのデータがロードされたか
  - メソッド
    - `WordListState` copyWith({`List<Vocabulary>`? words, `EndStatus`? endStatus, `bool`? isDataEnd}): 状態の一部を更新した新しいWordListStateを返す

- `sort_setting.dart`
  - `SortSetting`
  - プロパティ
    - `SortField` field: ソート項目（`createdAt`, `englishWord`）
    - `SortOrder` order: ソート順序（`asc`, `desc`）
  - メソッド
    - `SortSetting` copyWith({`SortField`? field, `SortOrder`? order}): 設定の一部を変更した新しいSortSettingを返す

- `bottom_index.dart`
  - `BottomNavIndexNotifier`
  - プロパティ
    - `int` state: 現在選択されているボトムナビゲーションバーのインデックス
  - メソッド
    - `void` setIndex(`int` newIndex): 状態（インデックス）を更新する

## Domain

- `batch_repository.dart`
  - `BatchRepository`
  - 責務
    - 一括で単語の訳語をデータベースから取得する
  - 保有データ: `Vocabulary`（`app_database.dart`に定義されていると推測）
  - メソッド
    - `Future<List<Vocabulary>>` fetchTranslationsBatch(`Set<String>` lookupKeys): 検索キー（英単語）のセットに対応する訳語エントリを一括で取得する

- `text_processor.dart`
  - `TextProcessor`
  - 責務
    - 英文の解析、トークン化、辞書検索、訳語の割り当てロジックを実装する
  - 保有データ: `Token`, `Vocabulary`
  - メソッド
    - `Future<List<Token>>` tokenizeAndTranslate(`String` text): 英文を解析し、訳語が割り当てられたTokenのリストを返す

- `translation_notifier.dart`
  - `TranslationNotifier`
  - 責務
    - アプリケーションの状態管理（Riverpod Notifier）
    - 英文入力の変更や翻訳トリガーに応じて、翻訳処理（トークン化・辞書検索）を制御する
    - 状態データ (`TranslationState`) を更新する
  - 保有データ: `TranslationState`
  - メソッド
    - `void` updateToken({required `Token` updatedToken}): 特定の単語の訳語情報を更新する
    - `void` updateOriginalText(`String` newText): 英文入力エリアの更新時に状態を更新し、スロットル後に翻訳処理をトリガーする
    - `void` pushTriggerButton(): 翻訳ボタン押下時に翻訳処理をトリガーする
    - `void` _processTranslation(): 翻訳処理（`TextProcessor`の呼び出しを含む）を実行する

- `card_repository.dart`
  - `CardRepository`
  - 責務
    - データベース（単語帳DB/内部辞書DB）から特定の英単語に対応する訳語エントリを取得する
  - 保有データ: `Vocabulary`, `InternalDictionaries`（DBエンティティ、推測）
  - メソッド
    - `Future<List<CardEntry>>?` fetchVocabularyEntries(`String` englishWord): 単語帳DBから`CardEntry`のリストを取得する
    - `Future<List<CardEntry>>?` fetchDictionaryEntries(`String` wordKey): 内部辞書DBから`CardEntry`のリストを取得する

- `cardlist_notifier.dart`
  - `CardListNotifier`
  - 責務
    - 辞書機能シートに表示する訳語のリスト（`CardListState`）を管理する
    - 対象のToken IDに基づき、リポジトリからデータを取得し状態を初期化する
    - 単語カードの表示/非表示の切り替え、新規作成、編集、削除などのロジックを処理する
  - 保有データ: `CardListState`
  - メソッド
    - `Future<CardListState>` build(): 初期化処理（対象Tokenの単語帳/辞書エントリを取得）
    - `Future<void>` toggleVisibility({required `CardEntry` entry}): 単語帳エントリの表示/非表示状態を切り替える

- `search_word.dart`
  - `SearchWordNotifier`
  - 責務
    - 「確定済み」の検索クエリ文字列を保持・管理する
  - 保有データ: `String`（検索クエリ）
  - メソッド
    - `void` refresh(): 確定クエリをクリアする
    - `void` setSearchQuery(`String` text): 確定クエリを設定する

- `typing_word.dart`
  - `TypingWordNotifier`
  - 責務
    - 「入力中」の検索クエリ文字列を保持・管理する
  - 保有データ: `String`（入力クエリ）
  - メソッド
    - `void` refresh(): 入力クエリをクリアする
    - `void` setQuery(`String` text): 入力クエリを設定する

- `sort_notifier.dart`
  - `SortSettingNotifier`
  - 責務
    - 単語リストのソート設定（`SortSetting`）を保持・管理する
  - 保有データ: `SortSetting`
  - メソッド
    - `void` setField(`SortField` newField): ソート項目のみを変更する
    - `void` setOrder(`SortOrder` newOrder): ソート順序のみを変更する
    - `void` reset(): 状態を初期値にリセットする

- `list_repository.dart`
  - `ListRepository`
  - 責務
    - データベースから単語リストを、ページング、フィルタリング、ソートを適用して取得する
  - 保有データ: `Vocabulary`（DBエンティティ）
  - メソッド
    - `Future<List<Vocabulary>>` fetchVocabulariesWithPaging({required `int` offset, required `int` limit, required `String` queryText, required `SortSetting` sorter}): 検索条件を適用した単語リストを取得する

- `list_notifier.dart`
  - `WordListNotifier`
  - 責務
    - 単語リストのページングとデータロードの状態（`WordListState`）を管理する
    - 検索/ソート設定の変更やスクロールに応じてデータ取得をトリガーする
  - 保有データ: `WordListState`
  - メソッド
    - `Future<WordListState>` build(): 初期化処理（最初のページをロード）
    - `Future<void>` loadNextPage({required `String` queryText}): 次のページをロードする
    - `Future<void>` reload({required `String` queryText}): フィルタ・ソート変更時などにリスト全体をリロードする
    - `Future<List<Vocabulary>>` _fetchData({required `int` offset, required `int` limit, required `String` queryText}): Repositoryから実際にデータを取得する（プライベートメソッド）

      - タップ時に`bottomNavIndexProvider`を更新し、`GoRouter`で画面遷移 (`context.go(...)`) を実行する
  - 子UIファイル
    - `drawer.dart`

## データベース

作成済みのテーブル

### 単語帳テーブル（Vocabularies）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー、自動インクリメント |
| englishWord | text | 英単語（小文字で保存、ユニーク制約） |
| japaneseTranslation | text | 日本語訳 |
| isHidden | boolean | 既定値は非表示か（0: false, 1: true） |
| memo | text | ユーザーメモ |
| created_at | dateTime | 登録日時 |
| updated_at | dateTime | 更新日時 |

### 内部辞書テーブル（InternalDictionaries）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー |
| key | integer | 英単語（小文字のみ） |
| word | text | 英単語（大文字・小文字混合、表示に用いる） |
| mean | text | 日本語訳 |
| memo | text | ユーザーメモ（nullable） |

### 英文テーブル（EnglishTexts）

| フィールド名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | integer | 主キー、自動インクリメント |
| original_text | text | 元の英文全体 |
| parsed_words_json | text | 解析された単語のリスト（JSON形式で保存） |
| created_at | dateTime | 保存日時 |
| updated_at | dateTime | 更新日時 |
